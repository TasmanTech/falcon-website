# Repo Maintenance

## Sources of truth
| Topic | Check against |
|---|---|
| Scripts | `package.json` in the root, `apps/front-end` and `apps/back-end` |
| Versions | `npm ls next react @nestjs/core typeorm` (not the docs, not memory) |
| Env vars | `process.env.*` and `config.get('*')` in the code, `.github/workflows/ci-cd.yml`, both Dockerfiles. Names only; never copy values from `.env`. |
| Deploy flow | `.github/workflows/ci-cd.yml` |
| Routes | `apps/front-end/app/**/page.tsx`, `app/sitemap.ts` |
| Colours and animations | `apps/front-end/app/globals.css` |

## Files to keep current
- `README.md` (root): overview, prerequisites, setup, scripts, structure, env var names, deploy flow, pointer to `.agents/`.
- `apps/front-end/README.md` and `apps/back-end/README.md`: app-specific setup, scripts, structure and env vars.
- `.agents/AGENTS.md` and the skills it indexes (`agent_training` skill for how to edit them).
- `apps/front-end/AGENTS.md` is generated by `next dev`; do not edit its marked block.

## Steps
1. Diff the docs against the sources above and recent history (`git log --oneline -30`).
2. Fix stale paths, script names, versions, hex values and routes. Remove claims the code cannot back up.
3. Keep root `package.json` copies of `@nestjs/*` and `react` aligned with the workspaces (`dependency_auditor` skill).
4. Report what changed and anything you could not verify.
