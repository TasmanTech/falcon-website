# UK/NZ English Formatting

Use this skill when auditing, writing, or refactoring text content for the website to ensure it complies with UK and New Zealand English spelling standards.

## Guidelines
1. **Spelling Differences**:
   - Use `ise` instead of `ize` (e.g., customise, categorise, specialise, prioritise).
   - Use `our` instead of `or` (e.g., colour, neighbour, labour, behaviour).
   - Use `re` instead of `er` (e.g., centre, fibre, metre, theatre).
   - Use `ce` instead of `se` for nouns (e.g., defence, licence, offence).
   
2. **Vocabulary**:
   - Depending on the context, prefer local terms over US equivalents where appropriate (though for a repair business, keep terms universally understandable but localised, e.g., "spanner" instead of "wrench" if applicable).
   
3. **Execution**:
   - When asked to apply this skill, scan the provided text or files and systematically replace all US English spellings with their UK/NZ equivalents. Check both user-facing copy and code comments/documentation.
